# Access metadata columns with \[\[

Access metadata columns with \[\[

## Usage

``` r
# S4 method for class 'AkoyaExperiment'
x[[i]]
```

## Arguments

- x:

  An
  [`AkoyaExperiment`](https://r-heller.github.io/phenoscapR/reference/AkoyaExperiment-class.md)
  object.

- i:

  Column name (character).

## Value

The requested metadata column.
