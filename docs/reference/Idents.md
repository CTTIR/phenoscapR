# Get Active Cell Identities

## Usage

``` r
Idents(object)

# S4 method for class 'SpatialCellData'
Idents(object)
```

- object:

  A
  [`SpatialCellData`](https://r-heller.github.io/phenoscapR/reference/SpatialCellData-class.md)
  object.

## Value

A character vector.
