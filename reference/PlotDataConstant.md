# Add a Constant Column

Add a Constant Column

## Usage

``` r
PlotDataConstant(data, column, value)
```

## Arguments

- data:

  A data frame.

- column:

  Name of the new column.

- value:

  Value written on every row.

## Value

`data` with the column.
