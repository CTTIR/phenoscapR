# Get Dimensions of a SpatialCellData Object

Get Dimensions of a SpatialCellData Object

## Usage

``` r
# S4 method for class 'SpatialCellData'
dim(x)
```

## Arguments

- x:

  A
  [`SpatialCellData`](https://cttir.github.io/phenoscapR/reference/SpatialCellData-class.md)
  object.

## Value

Integer vector: number of cells, number of markers.
