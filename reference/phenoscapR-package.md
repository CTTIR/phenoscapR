# phenoscapR: Read, Analyse, and Visualise Single-Cell Spatial Biology Data

Tools for importing, processing, analysing, and visualising single-cell
spatial biology data from multiplexed imaging platforms. Supports
cell-table quality control, marker normalisation, phenotype summaries,
spatial neighbourhood statistics, and explicit sample and
coordinate-frame registries. Patient-level inference enumerates label
allocations for declared contrasts and retains unavailable hypotheses
when adjusting for multiple testing. Grouped summaries expose
missingness, eligibility, and denominator provenance. Optional canonical
cell-table import uses 'cellspecR' <https://github.com/CTTIR/cellspecR>;
optional Self-Organising Nebulous Growths embeddings use 'songR'
<https://github.com/CTTIR/songR>. Both optional packages are available
from their respective GitHub repositories.
