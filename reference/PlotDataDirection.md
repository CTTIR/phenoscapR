# Count of Units in the Direction of an Estimate

Adds `k`, the number of units (patients) whose difference has the sign
of the summary estimate: `up` when the estimate is positive or zero and
`n - up` otherwise, as reported in "k/n patients".

## Usage

``` r
PlotDataDirection(data, n, up, estimate, into = "k")
```

## Arguments

- data:

  A data frame.

- n:

  Column with the number of units.

- up:

  Column with the number of positive differences.

- estimate:

  Column with the summary estimate.

- into:

  Name of the new column.

## Value

`data` with the count column.
